# Notas de incidentes

Aquí se reciben notas de errores, mejoras y resultados de pruebas de la comunidad. Usa una rama propia y abre un Pull Request a `main`; el equipo revisará el texto y la evidencia antes de incorporarlos.

## Nombre y contenido

Nombra cada nota `YYYY-MM-DD_NN_titulo-corto.md`, por ejemplo `2026-11-12_01_barra-de-progreso.md`. Si no conoces la fecha, usa `SIN-FECHA_NN_titulo-corto.md`. Copia la estructura de `PLANTILLA_NOTA.md` y no sobrescribas notas existentes.

Adjunta capturas en el Pull Request o inclúyelas en `evidencias/` y enlázalas desde la nota. Indica la versión de Project Zomboid, mods y versiones, pasos para reproducir, resultado esperado y observado. Revisa las capturas y logs para retirar nombres de usuario, rutas personales, identificadores de cuenta y datos del guardado que no sean necesarios.

Las notas históricas de la partida Jill se conservan localmente y no forman parte del repositorio público.
