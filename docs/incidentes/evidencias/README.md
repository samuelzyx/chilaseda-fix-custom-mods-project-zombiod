# Evidencias de incidencias

Guarda aquí capturas y otros archivos necesarios para reproducir una nota. Enlázalos desde el Markdown de la incidencia y conserva el nombre `YYYY-MM-DD_NN_descripcion.ext`. Antes de enviarlos, recorta o tapa nombres de usuario, rutas personales, identificadores de cuenta y datos de la partida que no sean necesarios. También puedes adjuntar las imágenes al Pull Request.
