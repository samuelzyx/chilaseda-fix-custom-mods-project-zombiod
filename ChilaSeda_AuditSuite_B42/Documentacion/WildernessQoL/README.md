# Wilderness QoL en Traducciones ES

## Traducciones

El catálogo central ya contenía parte de la traducción española. Se añadieron las 83 claves faltantes de Sandbox, Tooltip y UI. Las 42 claves de ContextMenu e IG_UI que ya estaban presentes conservan los textos revisados del catálogo central, aunque en algunos casos difieren de las traducciones archivadas.

## Identificación de objetos

La guardia de identificación ahora se carga desde `ChilaSeda_Translations_ES_B42/42/media/lua/client/ChilaSeda_WFIIdentificationFix.lua`. Solo reemplaza `WFI.isIdentified` cuando Wilderness QoL está cargado y la API existe. El catálogo de traducciones sigue funcionando aunque falte el mod original.

Los archivos del paquete separado y del parche anterior se conservaron como referencia en esta carpeta; sus IDs ya no se activan por separado.
