# Contribuir

Este repositorio reúne mods locales y parches para Project Zomboid Build 42. Antes de abrir una contribución:

- Mantén intactas las copias de mods originales; implementa cambios dentro del mod local correspondiente.
- Incluye una descripción del arreglo, dependencias y orden de carga en el README o LEEME del mod.
- No agregues partidas guardadas, registros de usuario, backups, credenciales, cachés, datos personales ni compilados temporales.
- Conserva únicamente los binarios que formen parte de la distribución del mod (por ejemplo, JARs incluidos por un parche).
- Indica la versión de Project Zomboid y los mods relacionados que usaste para revisar el cambio.

Las skills y hooks compartidos de Codex viven en `.agents/` y `.codex/`. Ajusta cualquier integración de usuario para que use rutas relativas del repositorio.
