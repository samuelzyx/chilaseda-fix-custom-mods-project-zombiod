# ChilaSeda Options Search (B42)

Agrega un filtro de busqueda a cada pestana de la ventana Opciones. Busca por texto visible en los controles de Project Zomboid y de los mods, incluidas etiquetas, descripciones, categorias, tooltips y opciones. Las coincidencias conservan la distribucion original y no cambian valores guardados.

La categoria de cada mod aparece en orden alfabetico en `Opciones > Mods`. El filtro de texto encuentra tanto la categoria como sus ajustes.

En `Teclas`, el filtro de texto busca la accion y la tecla mostrada. El control `Filtrar al presionar una tecla` captura la siguiente tecla pulsada y muestra solo las acciones asignadas a ella. `Esc` borra el filtro. El mismo filtro por tecla esta disponible en `Mods` para las opciones que usan asignaciones de teclas.

La normalizacion ignora tildes al comparar los textos.

## Uso

Abre `Opciones`. Cada pestana tiene un campo en la parte superior. Escribe para filtrar y borra el campo para recuperar todos los controles. En `Teclas` o `Mods`, pulsa el boton de filtro por tecla y luego la tecla que quieres buscar.
